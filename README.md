# ALFares App

تطبيق الفارس - تطبيق خدمات مالية ومصرفية شامل

## الميزات

- خدمات مالية متنوعة
- واجهة مستخدم عربية
- تصميم متجاوب
- خدمات حكومية
- خدمات تعليمية
- خدمات التأمين
- والمزيد...

## التشغيل المحلي

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

## النشر على GitHub Pages

```bash
npm run deploy
```

## التقنيات المستخدمة

- React 19
- TypeScript
- Vite
- CSS Modules
